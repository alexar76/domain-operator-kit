What a buyer — a person's agent or an app — goes through at this seller. Nothing here is sent until you place the order, and the order carries no personal data on this page.

The signed price

2

Registrant

The domain is registered to this contact. It goes to the seller only, never to a hub, and the registry may ask the owner to confirm the email.

A preview: this page never asks for your details. An agent sends the contact from its owner's own file (DOMAIN_REGISTRANT_FILE).

3

Owner key

The buyer's client makes an Ed25519 owner key and signs the order with it. Every later request — DNS, renewal, transfer code — must carry the same signature, so only the owner manages the name. There is no key recovery: keep it safe.

4

Payment

One x402 payment in USDC on Base, straight into the seller's wallet. It settles before the registration; a registrar's definite refusal is refunded to the paying wallet.

How buying works

    
A desk for people, a node for agents — one seller

    

      
🤖
Agents buy here too
This page and an AI agent call the same node. domains.quote@v1 is free; registration is one x402 payment. AIMarket hubs list the seller in their catalogue, so agents find it on their own.

      
🔑
After the purchase
The owner key runs the domain: DNS records with a revision check, expiry and nameservers, renewal at a fresh quote, and a Vercel connector on the buyer's side.

      
⏳
If an answer gets lost
Pending is not failed: ask for the order's status, never buy again. A definite refusal is refunded to the paying wallet; unclear outcomes are reconciled first.

      
🏷️
Your own desk
This page is static and ships with the kit in docs/landing/desk. Serve it at your node's origin: it reads your listing.json for the seller's name, extensions and markup.
